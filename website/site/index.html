A subset of Python with dependent types

Python that is checked before it runs.

A Pagda file is a Python file. It is type-checked by Agda before it runs, and its types can state facts about values: this list has ten items, this index is inside the list, this divisor is never zero. The price is a smaller language: no exceptions, no objects that change, no inheritance.

What the checker catches

Each program on the right was run through pagda to build this page. The panel under the code is what it printed.

An index past the end

xs[i] needs a reason that i is inside the list. A test in the code is a reason. Without one, the file is refused and nothing runs.

A None used as a value

A function that may return None says so in its type. The caller has to test for it, and after the test the name holds a plain value.

A value of the wrong shape

A type can mention a value. Vec[A, n + 1] is a list that has at least one item, so first cannot be called on an empty one.

A claim that is false

A return type can be a statement, and the function body is its proof. This one says that n + 0 equals n for every n.

How it works

A file opts in by importing dependent. Every other file runs as ordinary Python.

  1. You write PythonClasses, loops, lists, dicts, f-strings, with type annotations on every def.
  2. Pagda translates itThe file becomes an Agda program that means the same thing.
  3. Agda checks itAn error is reported against the Python line it came from.
  4. The Python runsThe types have done their work, so they cost nothing while the program runs.

What an accepted file promises

  • Every call gets arguments of the annotated types.
  • No index, key, pop or division fails.
  • No None is used as a value.
  • Every match finds a case.
  • Every loop and recursion ends.
  • Every assert holds.

Where the promise stops

  • An ordinary Python file can call a checked file with anything.
  • A def marked @trusted is believed without being read.
  • Checked files are a subset of Python. Exceptions, changing an object's fields, inheritance, floats, sets and file access are left out.
  • Pagda is new. There are no numbered releases yet.

Try it

Pagda is built from source with a C compiler and make. Checking needs Agda 2.8.0.

make                      # builds ./pagda
./pagda hello.py          # check, then run
./pagda --check hello.py  # check only
