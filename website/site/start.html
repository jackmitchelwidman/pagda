Get started

Build the pagda program, run a file, then check one.

What you need

  • A C compiler and make. gcc or clang. This is all that is needed to build Pagda and run ordinary Python files.
  • Agda 2.8.0. Needed to check files. The Agda documentation explains how to install it. Pagda uses none of Agda's libraries.
  • Python 3.12 or newer. Only for running Pagda's own tests, which compare its output with python3.

Build

In the folder that holds the Pagda source:

make          # builds ./pagda
make test     # runs every test

The result is one program, pagda, with its standard library inside it. Copy it anywhere on your PATH.

Run a Python file

pagda script.py        # run a file
pagda -c 'print(1)'    # run a string
pagda                  # interactive prompt

A file that does not import dependent runs as ordinary Python 3. Pagda's interpreter covers the core of the language and a small standard library. The FAQ lists what is in and what is out.

Your first checked file

A checked file starts with two lines. The first makes Python leave annotations alone. The second asks for checking.

from __future__ import annotations
from dependent import *

Save this as t01_hello.py. The Copy button gives the whole file, with those two lines.

Commands

CommandWhat it does
pagda file.pyChecks the file if it is a checked file, then runs it.
pagda --check file.pyChecks the file and does not run it.
pagda --agda file.pyPrints the Agda text the file is translated to.

Settings

NameMeaning
PAGDA_AGDAThe path of the agda program, when it is not on your PATH.
XDG_CACHE_HOMEWhere checked results are kept. The default is ~/.cache/pagda.

A file that passed is remembered, so Agda runs again only when the file changes. If agda cannot be started, a checked file is refused and does not run.

The same file under python3

A checked file is a Python file. It runs under python3 3.12 or newer with lib/dependent.py beside it (and lib/lemmas.py, if it uses the ready-made proofs), and prints the same output. There the types are not checked.
