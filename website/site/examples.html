Examples

Complete programs. Each was checked and run to build this page. They are also part of Pagda's test suite.

A report from a list of records

Ordinary Python: a class, lists, a dict, f-strings, a value that may be None, and a main. Nothing here is a proof. The checker still guarantees that mean never divides by zero and that hist[g] never misses.

An array of exactly ten items

A class can carry a proof about its own fields. size is a proof that items has ten items, so an Array10 with any other length cannot be built.

get asks its caller for a proof that the index is below 10. The inside line joins that with the size proof to show the index is inside the list. A list of the wrong length is refused:

Text, searching and loops

String handling, a dict of counts, a binary search and several while loops. The last def is a proof, imported from lemmas, that joining two lists adds their lengths.

Vectors with their length in the type

A dot product that only accepts two vectors of the same length.

A lookup that cannot go out of range

Fin[n] is a number below n. Indexing a Vec[A, n] with a Fin[n] needs no test and no proof at the call.
